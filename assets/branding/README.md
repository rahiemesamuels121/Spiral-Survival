# Spiral Survival artwork

`spiral_survival_original_exact.svg` is the user-supplied source. It contains an embedded PNG; `spiral_survival.png` is that exact embedded artwork, extracted without redrawing it. The PNG is bundled for Flutter menus, and `tools/export_app_icon.dart` generates Android launcher sizes and the splash artwork from it. The source SVG is retained for reference and is not bundled into the APK.

Menu palette: midnight blue `#091A2B`, blue stone `#142E45`, amber `#FFC34A`, lava red `#E63C25` and sky blue `#64C9EE`. Tropical foliage remains green against the blue-toned forest floor, with warm stone and flower accents.
